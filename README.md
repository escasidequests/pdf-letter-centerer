# PDF Letter Centerer

A one-page website that takes a PDF and places every page at its **true physical size**, centered on a **US Letter (8.5 × 11 in)** page.

- Runs entirely in the browser. Files are never uploaded.
- Multi-page PDFs: each page goes on its own letter page.
- Orientation is chosen per page (wide pages go on landscape letter).
- Pages larger than letter: choose **Keep real size** (clipped) or **Shrink to fit**.

Built with [pdf-lib](https://pdf-lib.js.org/). Hosted on GitHub Pages.

**Printing tip:** print at "Actual size" / 100%, not "Fit to page".
